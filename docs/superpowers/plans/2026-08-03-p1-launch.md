# P1 Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the funded first build (P1) of the folk-medicine web app: a single self-hosted binary that lets district staff enter healer/recipe/case data and lets the public read and search it.

**Architecture:** One Go binary serves a JSON API (Gin) and an embedded Next.js static export (ADR-0001). Data is in SQLite through GORM (pure-Go `glebarez/sqlite` driver, so the binary stays cgo-free); GORM's dialect layer makes the later move to PostgreSQL a driver swap. The binary terminates TLS itself with ACME. The Next.js app is a client-rendered SPA that calls the JSON API with a session cookie; Node is a build-time tool only.

**Tech Stack:** Go 1.23+, **Gin** (`github.com/gin-gonic/gin`), **GORM** (`gorm.io/gorm`) with the **pure-Go** driver `github.com/glebarez/sqlite`, `golang.org/x/crypto/bcrypt`, `golang.org/x/crypto/acme/autocert`, `github.com/disintegration/imaging`, `github.com/xuri/excelize/v2`; Next.js 15 / React 19 static export, plain `fetch`, Playwright.

## Global Constraints

- **TDD, always.** Failing test → confirm fail → minimal code → confirm pass → refactor. No exceptions. A test with no assertion is not a test.
- **Single binary, cgo-free.** SQLite goes through **GORM + `github.com/glebarez/sqlite`** (pure Go). **Never** use `gorm.io/driver/sqlite` (it pulls cgo `mattn/go-sqlite3`) or any other cgo dependency. `CGO_ENABLED=0 go build` must succeed.
- **All DB access through GORM** — no hand-written dialect-specific SQL except the two documented raw statements (backup `VACUUM INTO`, and `PRAGMA`s in the DSN). GORM's portability is what makes the P5 Postgres move cheap (ADR-0001).
- **Auth = server-side session.** bcrypt password hash; a GORM `Session` row (token hash, user, expiry); Gin middleware loads the user. **No JWT.** Instant revocation by deleting the row / deactivating the user.
- **CSRF defense = `SameSite=Strict`.** The session cookie is `HttpOnly; Secure; SameSite=Strict`. There is **no** CSRF token and no `X-CSRF-Token` header. An Origin/Referer check middleware guards unsafe methods as a second line. (Satisfies SRS NFR-SEC-6; the defense lives in the cookie, not a token.)
- **Go style:** uber-go style guide; modern Go; organized imports (stdlib, third-party, local — sorted). Never name a local package the same as a stdlib package (the image store package is `media`, not `image`).
- **JS/TS style:** Google TS/JS style guide; organized imports.
- **PDPA:** private fields (`phone`, `consent_obtained`, `consent_date`, `updated_by`, `updated_at`) never appear in any public response or payload. The public read layer selects explicit public columns and filters `consent_obtained = true` — including on the recipe/case paths, not only the doctor list.
- **i18n:** Thai is the UI default; an English toggle switches labels only; record content is never translated.
- **Commands:** prefix shell commands with `rtk` (e.g. `rtk go test ./...`).
- **Commit** after every green step. Small commits.
- **Scale targets (provisional):** ~500 doctors, ~5k recipes; list < 1 s, search < 2 s.
- **Reference:** SRS (`docs/superpowers/specs/2026-08-03-srs.md`) and data model (`docs/superpowers/specs/2026-08-03-data-model-and-form-design.md`). Requirement IDs (FR-*, NFR-*) point to the SRS.

**Interfaces:** **[FIX-4]**
- `db.Open(path string) (*gorm.DB, error)` — opens with `glebarez/sqlite`, sets WAL + busy_timeout + foreign_keys via DSN pragmas, sets a modest pool.
- `db.Tx(g *gorm.DB, fn func(tx *gorm.DB) error) error` — thin wrapper over `g.Transaction`; **all queries inside a transaction use the passed `tx`, never the outer handle** (avoids the single-writer deadlock).

Pool: `SetMaxOpenConns(4)` (WAL allows concurrent readers), `SetMaxIdleConns(4)`. Writes serialize inside SQLite; `busy_timeout(5000)` retries on contention. Safe with GORM because a `Transaction` holds one connection for its whole closure and every in-tx query uses that same `tx`.

```go
package db

import (
	"fmt"

	"github.com/glebarez/sqlite"
	"gorm.io/gorm"
)

// Open opens a SQLite database at path via the pure-Go glebarez driver.
func Open(path string) (*gorm.DB, error) {
	dsn := fmt.Sprintf("file:%s?_pragma=busy_timeout(5000)&_pragma=journal_mode(WAL)&_pragma=foreign_keys(1)", path)
	g, err := gorm.Open(sqlite.Open(dsn), &gorm.Config{})
	if err != nil {
		return nil, fmt.Errorf("open sqlite: %w", err)
	}
	sqlDB, err := g.DB()
	if err != nil {
		return nil, err
	}
	sqlDB.SetMaxOpenConns(4)
	sqlDB.SetMaxIdleConns(4)
	return g, nil
}

// Tx runs fn inside a transaction. Every query in fn MUST use tx.
func Tx(g *gorm.DB, fn func(tx *gorm.DB) error) error {
	return g.Transaction(fn)
}
```

### Task 12: Origin/Referer check middleware [replaces CSRF token]

**Files:** Create `internal/auth/origin.go`, `internal/auth/origin_test.go`.
